# Lassofem 1.0 TEST
Native Java/Canvas Android 8+ Nagenawa rectangular-loop puzzle.

Draw square or rectangular closed loops between cell centers. You may leave cells unused. Loops may cross only straight through a cell, with opposite sides connected, and cannot share any edge, branch or touch at a turn. Each A-F room quota counts cells visited by any loop; count a crossing cell once. Tap between neighboring centers to toggle an edge. Twelve unique 4x4 six-room quota boards have twelve distinct solutions. All twelve solutions use two loops; the first four include crossings. The rules do not require exactly two loops.

Saved lasso palette and A-F room labels, GG007 icon/menu/site/privacy, unlimited undo/reset. Offline, no ads, analytics, account or requested permissions. Settings and completed-puzzle marks stay on device. External studio link opens the browser.

Independent Python enumeration builds all 36 possible rectangles and all 135 compatible nonempty collections. Java independently enumerates the rectangle collections using corner and perimeter sets, checking every collection plus 50000 random 24-edge masks per board against production straight-through path tracing and bounding-box perimeter validation. Unique solutions, bounds, solve, undo and replay pass. Adapter menu, settings, privacy, edge taps, next, levels and persistence pass. Actual drawing pixels inspected, not phone screenshots. Phone runtime, performance and browser handoff QA incomplete. Signed TEST only; not final or Play published.

Live 803-entry registry, 117 recovered README/source records and exact Pairhaven cumulative stage found no Nagenawa, Nagewawa or rectangular-loop match. Shares Cloverroad room quotas and loop-edge input, but multiple rectangular loops with straight-through crossings replace one noncrossing continuous-per-room loop and border adjacency rules. Unlike Springloop, loops have no spring or equal-per-room visit rule. Known Nagenawa genre, not a global invention. Partial recovered source corpus, not ALL-local.
